# Career Intelligence for Job Seekers

## About the Project

This project uses Advanced Excel to analyze career and job-related data and present useful information for job seekers.

## Tools Used

- Microsoft Excel
- Advanced Excel
- Data Cleaning
- Data Analysis
- Formulas
- Pivot Tables
- Charts
- Data Visualization

## Project Objective

The main objective of this project is to organize and analyze job-related information and present it in a clear and useful way for career decision-making.
